SKILIDO SCHOOL GROWTH PARTNERSHIP MASTERCLASS WEBSITE

FILES
- index.html: the complete responsive single-page website.
- assets/: selected page images rendered from the uploaded Skilido School Sales Master Script PDF.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the skilido_masterclass folder.
3. Open index.html in Chrome, Edge, Firefox or Safari.
4. Keep the assets folder beside index.html. Do not move index.html out of its folder.

- Copyable scripts
